# HoloVis (Fabric 1.21.4, client-side)

Prawy Shift otwiera menu z kolumnami modułów (przeciągaj panele za nagłówek, PPM / strzałka = ustawienia, pole wyszukiwania).
**L** w menu otwiera edytor HUD (przeciągasz FPS, koordynaty i Spotify).

- **PVP:** Hitbox (styl, cele, wypełnienie, kolor).
- **Dźwięki:** Hit Sound, Kill Sound, Click Sound (kliknięcia w menu + machnięcie ręką w powietrze).
  Lista dźwięków rozwija się po kliknięciu; własne pliki .wav: przeciągnij na okno gry przy otwartym menu
  albo wrzuć do `config/holovis/sounds`.
- **Świat:** Custom Sky (tylko Overworld).
- **HUD:** Watermark, Koordynaty, Spotify, Edytor HUD.
- **Klient:** Akcent GUI, Gradient, Tło GUI, Kolor napisu.

## Spotify
Windows 10/11: odczyt i sterowanie przez systemową sesję multimediów (bez logowania).
Otwórz czat i najedź na element Spotify: tekst piosenki (lrclib.net), suwak przewijania i przyciski.
Skróty (Sterowanie → HoloVis): `[` poprzedni, `]` następny, `\` pauza/play.
